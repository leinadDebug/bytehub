Getting Started

Introduction

Welcome to the StayFinder Platform Documentation. This comprehensive guide is designed to assist administrators and developers in understanding, utilizing, and maintaining the StayFinder system. Here, you'll find detailed information on system architecture, API references, admin feature guides, troubleshooting tips, and more. Our goal is to provide you with all the necessary resources to effectively manage and enhance the StayFinder platform.

Navigating the Documentation

Use the sidebar on the left to navigate through different sections of the documentation. Each section covers a specific aspect of the StayFinder platform, from initial setup and API usage to troubleshooting common issues and understanding the system's architecture. The search bar at the top allows you to quickly find specific topics or keywords within the documentation.

Key Features

StayFinder offers a robust set of features for managing accommodations, bookings, and user interactions. Key features include: - **Accommodation Management:** Add, update, and manage property listings with detailed information and availability. - **Booking System:** Handle reservations, cancellations, and modifications with real-time updates. - **User Management:** Manage user accounts, roles, and permissions within the platform. - **API Access:** Utilize our comprehensive API for integrating StayFinder with other systems and applications. - **Reporting and Analytics:** Access detailed reports on bookings, revenue, and user activity.

Super Admin Features

Introduction

As a SuperAdmin, you have complete control over the platform, allowing you to manage users, lodges, payments, and system-wide settings. To get started, we recommend exploring the sections below to understand your key responsibilities and capabilities.

User Management

  • Approve Host Signups: Hosts cannot operate until approved by SuperAdmin.
  • Ban or Remove Users: Temporarily or permanently remove students, hosts, or owners who violate rules.
  • Role Management: Upgrade or downgrade user roles (e.g., Host → Owner, Student → Host).
  • View Platform-Wide User List: Access all users, their roles, status, and activity logs.

Lodge Management

  • Delete Any Lodge: Remove problematic lodges from the platform.
  • Edit Lodge Details: Modify or correct lodge information if the host cannot.
  • Oversee All Lodges: View all lodges across the platform, including bookings and reports.

Platform Configuration

  • Payment Gateway Management: Configure global payment integrations like Stripe, Paystack, and Flutterwave.
  • Set Transaction Fees & Payout Rules: Adjust fees, payout schedules, or commission percentages.
  • Global Settings: Manage system-wide settings such as themes, currency options, notification templates, and default policies.

Reporting & Monitoring

  • Platform Usage Analytics: Track active users, lodges, bookings, complaints, and revenue trends.
  • Audit Logs: See detailed logs of all actions performed across the system.
  • Financial Reports: Overview of platform-wide revenue, fees collected, and payout summaries.

Security & Maintenance

  • Access All Data: Full access to sensitive or private data for troubleshooting.
  • Monitor Suspicious Activity: Detect unusual behavior such as multiple failed logins or fraud attempts.
  • Emergency Actions: Temporarily disable parts of the system or freeze transactions if needed.

Communication

  • Broadcast Messages: Send announcements or alerts to all users, hosts, or owners.
  • Support Escalation: Access unresolved complaints and escalate them if hosts fail to act.

For detailed instructions on performing these actions, refer to the 'Admin Features' section. For developer integrations, see the 'API Reference', and for issues or questions, consult 'Troubleshooting' or contact 'Support'.
